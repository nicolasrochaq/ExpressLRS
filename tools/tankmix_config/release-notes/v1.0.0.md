## TankMix v1.0.0: tank mixing for the RadioMaster T8L

A small app to install, set up, build and flash the tank mix on the **RadioMaster T8L** internal ExpressLRS module. The T8L has no screen for a mixer and the ExpressLRS web UI has no tank mix, so the mix runs in the TX module and the receiver stays stock.

**Download `TankMix-v1.0.0.zip` below**, unzip it and start:
- **Windows:** `TankMix.bat`
- **macOS:** `TankMix.command` (first time: right-click → Open)
- **Linux:** `./tankmix.sh`

### What it does
- Checks for Python 3.8+, PlatformIO and Git, with install links for anything missing
- Downloads any **ExpressLRS 3.5.0 or newer** (tested up to 4.1.0), or opens one you have, and installs the mod in it
- Mix editor (channels, steering %, deadbands, reverses) with validation and a live preview that uses the firmware's own math
- Builds the T8L firmware with your binding phrase and flashes it over WiFi (`10.0.0.1`)
- **English and Portuguese** interface

Bench-test before driving: receiver failsafe set to "No pulses" or "Set position center", never "Last position".

Full documentation: [tools/tankmix_config/README.md](https://github.com/nicolasrochaq/ExpressLRS-T8L-TankMix/blob/t8l-tankmix/tools/tankmix_config/README.md) · [TANKMIX.md](https://github.com/nicolasrochaq/ExpressLRS-T8L-TankMix/blob/t8l-tankmix/TANKMIX.md)

## Português

App para instalar, configurar, compilar e gravar o tank mix no módulo ExpressLRS interno do **RadioMaster T8L**. O T8L não tem tela para mixer, e a interface web do ExpressLRS não tem tank mix. Por isso o mix roda no módulo TX, e o receptor continua original.

**Baixe o `TankMix-v1.0.0.zip` abaixo**, extraia e abra:
- **Windows:** `TankMix.bat`
- **macOS:** `TankMix.command` (na primeira vez: botão direito → Abrir)
- **Linux:** `./tankmix.sh`

### O que ele faz
- Confere Python 3.8+, PlatformIO e Git, com links para instalar o que faltar
- Baixa qualquer **ExpressLRS 3.5.0 ou mais novo** (testado até a 4.1.0), ou abre um que você já tenha, e instala o mod nele
- Editor do mix (canais, direção %, zonas mortas, inversões) com validação e prévia ao vivo, usando a mesma conta do firmware
- Compila o firmware do T8L com a sua binding phrase e grava por WiFi (`10.0.0.1`)
- Interface em **português e inglês**

Teste na bancada antes de usar: failsafe do receptor em "No pulses" ou "Set position center", nunca "Last position".
